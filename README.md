# 纸片枪战 · 训练场原型

网页版第三人称纸片人射击游戏的第一个可玩原型。

## 怎么运行

双击 `start.bat`，会启动本地服务器并自动打开浏览器（http://localhost:5173）。需要电脑上装有 Node.js 或 Python 其中一个。

不能直接双击 `index.html` 打开，浏览器禁止网页从本地磁盘读取模型文件，必须经过本地服务器。

## 操作

| 按键 | 作用 |
|---|---|
| WASD | 移动 |
| 空格 | 跳跃 |
| 鼠标左键 | 射击 |
| R | 换弹 |
| 鼠标右键（按住） | 瞄准：移动变慢一半、散布变小、镜头拉近；狙击枪会开 3 倍镜（不开镜时狙击枪散布很大） |
| C / 左 Ctrl（按住） | 纸化：侧身变成一张纸，正面几乎打不中，移动更快，不能开枪，消耗能量 |
| E | 纸鹤突进：朝移动方向冲刺（5 秒冷却） |
| Q | 墨水炸弹：抛物线投掷，范围伤害（9 秒冷却） |
| 1–8 / 滚轮 | 切换武器：突击步枪、冲锋枪、轻机枪、狙击枪、手枪、左轮、霰弹枪、火箭筒 |
| V | 切换第一人称 / 第三人称（第一人称用单独的手臂模型，右键用枪上的瞄具瞄准） |
| Esc | 暂停 |

训练场里有 5 个会横移的纸片靶，它们会不时纸化躲避，也会朝你丢纸飞机。纸化可以让纸飞机从你身边擦过。

## 代码结构

```
index.html        页面和 HUD 结构
style.css         界面样式（纸片描边风格）
src/config.js     角色列表、素材路径、所有数值（改手感从这里开始）
src/main.js       渲染、加载地图和角色、输入、主循环、射击判定
src/viewmodel.js  第一人称手臂：从当前角色复制出只有手臂的模型，和一把单独的枪固定在镜头前，单独渲染在最上层
src/player.js     玩家：移动物理、纸化、技能、持枪姿势和走路动画、第三人称镜头
src/dummies.js    纸片靶：横移、纸化、丢纸飞机、命中盒
src/fx.js         弹道、火花、墨水炸弹和爆炸
src/weapons.js    8 把枪的数值（伤害、射速、弹匣、换弹、散布、后坐力）和模型加载
src/anim.js       角色动作：下半身跑跳按速度混合、上半身随准星瞄准，叠加开枪/换弹/翻滚/倒地
src/hud.js        血量、弹药、技能冷却、伤害数字、击杀提示
src/audio.js      音效播放
tools/build_audio.py 从原始音效包生成 Asset/Audio 下的所有音效（开火、换弹分段、命中、击杀、爆炸）
tools/gunlab.html 枪械转换工具：把 Infima 枪械 FBX 组装（带骨骼）导出成 Asset/Weapon/Guns/*.glb，并生成换弹动画
tools/reloads.js  8 把枪的换弹关键帧（枪身、弹匣、拉机柄、左手位置），改完重新跑 gunlab 就会更新 Asset/Animation/Reload/*.json
tools/bake.html   动作烘焙工具：把 Quaternius 动作包转换成所有 VRM 角色通用的 Asset/Animation/ual_vrm.json
vendor/           three.js 0.186 和 @pixiv/three-vrm 3.5（本地副本，不依赖网络）
Asset/            模型、场景、音效（授权见 Asset/LICENSES.md）
```

## 加新角色

把 `.vrm` 文件放进 `Asset/Character/VRM/`，然后在 `src/config.js` 的 `CHARACTERS` 里加一行。

## 已知限制

- 动作包里只有向前跑的动画，侧移和后退靠转动髋部、倒放动画来模拟。
- 地图是 three.js 的 FPS 测试地图，后续换成自己设计的地图。
- 目前是单机训练场，还没有联网对战。
